# SmartReviewDetector

## Phase 1: Project Setup & UI

This project is structured based on the Development Roadmap. Phase 1 focuses on setting up the responsive UI using HTML5, CSS3, and Vanilla JavaScript, with a Flask backend skeleton.

### How to Run:
1. Create a virtual environment: `python -m venv venv`
2. Activate it: `.\venv\bin\Activate.ps1` (or `source venv/bin/activate` on Mac/Linux)
3. Install dependencies: `pip install flask`
4. Run the app: `python app.py`

### Features in Phase 1:
- Glassmorphism UI
- Responsive CSS Grid and Flexbox layouts
- Dark mode theme
- Smooth animations and loading spinner
- Dummy Result Page
